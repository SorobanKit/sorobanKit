- Standardized API error responses across payment endpoints to RFC 7807 problem details.
- Enhanced transaction validation for Stellar memo encoding and character sets.
- Improved documentation and contributing guidelines for local test runs.

### Fixed
- Fixed CSV output escaping and added webhook delivery metrics.
- Resolved sequence number verification against Horizon during multi-sig operations.
- Fixed log purging and per-table cleanup counts in cleanup cron worker.

## [1.0.0] - 2026-10-15

### Added
- Initial production release of Stellar Tags payment routing platform.
- Soroban smart contract payment router (`payment_router`).
- Backend payment platform and REST API server (`stellar-payment-platform`) with Prisma ORM.
- React + Vite merchant payment dashboard (`payment-dashboard`).
- Integration with `@creit.tech/stellar-wallets-kit` for Freighter, Albedo, and xBull wallet connectivity.
- Docker Compose development profiles (`dev`, `full`, `test`, `integration`).
